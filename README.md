# Hà Giang with Ri Ri

Two pages: index.html (home) and ha-giang-loop.html (the Loop).

## Replacing the live site on GitHub

1. Open the repo on github.com.
2. Delete the old README.md (open it, click the trash icon, commit). All other files with the same names get replaced in the next step.
3. Click Add file > Upload files and drag in all the files from this folder at once:
   index.html, ha-giang-loop.html, support.js, styles.css, _ds_bundle.js, ri-ri.png, favicon.svg, README.md
4. Click Commit changes.
5. Keep the existing .nojekyll and CNAME files in the repo. Do not delete them.

GitHub Pages republishes within a minute or two. Hard-refresh (Ctrl+Shift+R / Cmd+Shift+R) to see the new version.
